## ![🤔](https://fonts.gstatic.com/s/e/notoemoji/17.0/1f914/32.png) Respuestas a las preguntas  
  
1. ¿Por qué clonas desde GitHub en vez de copiar con pendrive? Porque en GitHub está la versión buena y actualizada de mi trabajo, y al clonar me bajo también la carpeta .git con el historial y el remote. Así puedo seguir haciendo pull y push desde casa, y la copia es idéntica a la del centro. Con un pendrive podría llevarme una versión vieja o incompleta.  
2. ¿Por qué generas una clave SSH nueva en casa? Porque la clave privada no se copia de un equipo a otro: cada ordenador tiene la suya. En GitHub se pueden tener varias claves a la vez (la del centro y la de casa), y si un día pierdo un equipo, solo borro su clave.  
3. ¿Dónde NO debe estar la bóveda? En OneDrive (ni en ninguna carpeta sincronizada con OneDrive). Git y OneDrive se pelean y aparecen ficheros duplicados del tipo `-MiPC.md`. La bóveda va en una carpeta local de mi usuario, como Documents/SOR. Mi "nube" es GitHub.
